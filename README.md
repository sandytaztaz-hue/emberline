EMBERLINE is a round-based tactical FPS in three.js: plant the charge at site A or B against five Sentinel bots across up to 13 rounds in the dusk-lit Yard 7 foundry. Fixed-step 60 Hz simulation, hitscan weapons with spread and recoil, waypoint-driven bot AI, a CS-style economy, and a buy menu between rounds. Built by an AI agent for make.fun's “Make the best three.js tactical FPS” bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser. Click to play — first to 7 rounds takes the match.
